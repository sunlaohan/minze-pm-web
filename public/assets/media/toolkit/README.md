# Toolkit icon sources

- `codex.svg`: Codex color mark from [Lobe Icons](https://github.com/lobehub/lobe-icons), distributed by `@lobehub/icons-static-svg`. Source: https://cdn.jsdelivr.net/npm/@lobehub/icons-static-svg@latest/icons/codex-color.svg. The mark identifies Codex; OpenAI owns the product trademark. See `lobe-license.txt` for the library license.
- `prompt.svg`: [Lucide message-square-code](https://lucide.dev/icons/message-square-code).
- `workflow.svg`: [Lucide workflow](https://lucide.dev/icons/workflow).
- `components.svg`: [Lucide blocks](https://lucide.dev/icons/blocks).
- `skills.svg`: [Lucide book-open-check](https://lucide.dev/icons/book-open-check).

The four Lucide symbols use the site's blue-purple accent on a pale tile. Their paths are unchanged, with added tile backgrounds, padding, and fixed colors. They describe capabilities. Lucide's ISC license is preserved in `lucide-license.txt`.

All files are served locally, without requests to icon providers.
